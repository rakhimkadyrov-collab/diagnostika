# Где брать данные по Казахстану

Ссылки проверены 03.10.2026. Перед тем как написать «данных нет», пройти по этому списку.

## Статистика рынка

**Бюро национальной статистики АСПиР РК** - `stat.gov.kz`
Разделы отраслевой статистики: промышленное производство, строительство, транспорт, сельское и лесное хозяйство, энергетика, услуги, туризм, инвестиции, структурная статистика предприятий, ИКТ. Плюс цены, внешняя и взаимная торговля, труд и доходы, демография, уровень жизни.
Чего там нет: разбивки по узким продуктовым нишам, долей отдельных компаний, цен конкретных сделок.

## Компания и её владельцы

**Государственная база данных юридических лиц** - через `egov.kz`
По БИН: полное и сокращённое наименование, дата регистрации, юридический адрес, основной вид деятельности, руководитель, учредители, уставный капитал, статус.

**Единый реестр должников** - через `egov.kz`
Долги, по которым идёт принудительное взыскание.

**Комитет госдоходов МФ РК** - `kgd.gov.kz/ru/all/services`
Поиск налогоплательщика, сведения о наличии или отсутствии налоговой задолженности.

**Судебный кабинет** - `office.sud.kz`
Судебные дела и акты. Проверка, не является ли контрагент стороной спора.

## Выручка и контракты

**Портал госзакупок** - `goszakup.gov.kz`
Весь цикл электронный: тендеры, договоры, акты поставки, счета-фактуры, реестр недобросовестных поставщиков. Через историю закупок восстанавливается выручка поставщика по госсектору - это один из немногих способов получить проверяемую выручку частной компании в РК. Доступ платный, оплата раз в год.

## Публичные компании

**KASE** - `kase.kz/ru/listing/issuers/`
Карточки эмитентов с капитализацией, активами, обязательствами, выручкой и прибылью. Финансовая и консолидированная отчётность листинговых компаний, сообщения о листинге, проспекты и инвестиционные меморандумы.
Для казахстанского эмитента это первое, что поднимается, и поднимается самостоятельно.

## Макро

Курс, базовая ставка, инфляция - Национальный банк РК и БНС. Ссылку и дату брать в момент использования, не по памяти: значения меняются ежемесячно.

## Чего в открытых источниках по РК нет

По большинству ниш, кроме сырья, финансового сектора, листинговых эмитентов, недвижимости крупных городов и госзакупок, публичной статистики не существует. Поиск вернёт либо пустоту, либо чужие оценки без методики - такие оценки цитировать нельзя, их происхождение не проверяется.

Закрывается полем:

| Пробел | Способ |
|---|---|
| Объём ниши | Интервью с 3-5 участниками рынка, оценка снизу вверх по числу точек и среднему чеку |
| Доли конкурентов | Выручка из госзакупок, численность персонала, число точек, оборот по данным поставщиков |
| Цены конкурентов | Прайсы, тайный покупатель, коммерческие предложения |
| Поведение клиентов | Опрос базы, замер в точке продаж, выгрузка из CRM |
| Состояние активов | Выезд на объект, техническая экспертиза |

Пробел с названным способом закрытия - рабочий результат. Пробел, заполненный оценкой на глаз, - брак.
