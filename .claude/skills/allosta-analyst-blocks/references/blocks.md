# Двенадцать блоков - развёрнутые чеклисты

Для каждого блока: что обязательно посчитать, какой таблицей отдать, чем закончить. Статусы цифр - по разделу 1 SKILL.md.

---

## Блок 1. Объём и потенциал рынка

Считать:
1. Сверху вниз: от отраслевого объёма к сегменту компании, с показанными шагами.
2. Снизу вверх: число потенциальных клиентов × средний чек × частота покупки.
3. CAGR на 5 лет и из чего он складывается.
4. Чувствительность: какое допущение сильнее всего двигает результат.

| Показатель | Сверху вниз | Снизу вверх | Принято к работе | Статус |
|---|---|---|---|---|
| TAM | | | | |
| SAM | | | | |
| SOM | | | | |

Источник / статус. Дата.

Обязательно: если методы расходятся больше чем на 30%, назвать причину и сказать, какой оценке верить. Нераскрытое расхождение обесценивает обе цифры.

Заканчивать: достижимая доля рынка за 3 года и выручка, которая за ней стоит.

## Блок 2. Конкурентная среда

- Прямые конкуренты: до 10 игроков. Доля, выручка, источники финансирования - только из проверяемого: отчётность, госреестры, тендерные площадки, публикации. Нет цифры - прочерк.
- Косвенные: до 5 смежных компаний, способных зайти на рынок, и что их пока держит.
- По каждому: ценообразование, ключевое предложение, целевой клиент, сильные и слабые стороны, шаги за 12 месяцев.
- Карта «цена - ценность» таблицей координат.
- Что делает защищённым: патенты, долгосрочные контракты, доступ к ресурсу, административный ресурс, масштаб, переключательные издержки клиента.
- Белые пятна: ниши, которые не занял никто, и почему.
- Уровень угрозы: низкий, средний, высокий.

| Игрок | Доля | Выручка | Модель цены | Защищённость | Угроза | Статус |
|---|---|---|---|---|---|---|

## Блок 3. Сегменты и клиенты

3-4 сегмента. По каждому: профиль, боли (до 5), критерий успеха, механика решения о покупке и её участники, топ-3 возражения, триггеры поиска решения, готовность платить.

Плюс: размер сегмента в деньгах, доля в текущей выручке, матрица «привлекательность × доступность».

Обязательно разделить: что выведено из материалов, а что - из общих представлений об отрасли. Второе целиком идёт под статусом «допущение» с указанием, каким исследованием проверяется.

## Блок 4. Отраслевые тренды

- Макротренды: 5 факторов - экономика, регулирование, технологии, демография, экология.
- Микротренды: до 7 изменений за последние 12 месяцев.
- Технологические сдвиги: что меняет правила и когда станет массовым.
- Регулирование РК: принятые и готовящиеся изменения, со ссылками на документы.
- Куда идут деньги: сделки M&A, венчур, госпрограммы, крупные capex.
- Горизонт: 0-1 год, 1-3 года, 3-5 лет.

| Тренд | Горизонт | Влияние 1-10 | И что из этого следует | Источник |
|---|---|---|---|---|

Тренд без подтверждающего источника не включается вообще.

## Блок 5. SWOT и пять сил Портера

SWOT: по 5-7 пунктов в каждом поле, каждый - с доказательством. Пункт без доказательства не пишется.

Кросс-анализ, он же главная ценность блока:
- **ход SO**: какие сильные стороны ложатся на какие возможности и что из этого можно сделать за 12 месяцев;
- **риск WT**: какое сочетание слабости и угрозы способно обрушить бизнес, и что держать под наблюдением.

|---|---|---|

| Власть покупателей | | |
| Соперничество | | |
| Заменители | | |
| Новые игроки | | |

Заканчивать ответом: компания зарабатывает благодаря структуре отрасли или вопреки ей. Второе означает, что результат держится на людях и уйдёт вместе с ними.

## Блок 6. Ценовая стратегия

- Аудит цен конкурентов со ссылками на прайсы.
- Цена от ценности: сколько клиент экономит или зарабатывает и какая доля изымается в цену.
- Цена от затрат: нижняя граница по себестоимости.
- Эластичность: по собственным данным продаж, не по учебнику. Нет данных - так и сказать.
- Три тарифа с разделением функций и целевыми долями продаж.
- Политика скидок: кому, когда, сколько и в обмен на что.
- Прогноз выручки в трёх сценариях при переходе на новую модель.

Все рекомендации в тенге и долларах, с курсом и датой курса.

## Блок 7. Выход на рынок

Фазы: подготовка 60 дней, запуск 1 неделя, закрепление 90 дней.

- До 7 каналов с ценой лида и возвратом **для рынка РК**.
- Сообщение: ценностное предложение, 3 поддерживающих тезиса, доказательства.
- Контент под каждый этап воронки.
- До 5 партнёров и что они получают взамен.
- Распределение бюджета по каналам.
- 10 метрик с целевыми значениями.
- Топ-5 рисков запуска и план на случай реализации.
- Три быстрые победы в первые 14 дней.

## Блок 8. Путь клиента

Этапы: осведомлённость, рассмотрение, решение, первые дни, регулярное использование, лояльность, отток.

По каждому: действия и ожидания клиента, точки контакта, точки трения, возможность превысить ожидание, метрика, действие по улучшению с оценкой усилия.

Отдельно: причины оттока и ранние признаки, по которым он виден заранее.

Нет данных по воронке - назвать, какие замеры поставить, прежде чем карта станет рабочей.

## Блок 12. Синтез стратегии

1. Резюме на три абзаца, читается за две минуты.
2. Где бизнес сегодня - честно, включая неприятное.
3. Три пути: A консервативный, B сбалансированный, C агрессивный. По каждому: результат в деньгах, инвестиции, сроки, ключевые риски.
4. Рекомендованный путь и почему он.
5. Пять действий на 90 дней по убыванию важности.
6. Ресурсы: люди, деньги, инструменты.
7. Матрица решений на следующие 10 развилок: критерий - порог - решение.
8. Если бы был один час: что проверить и что сделать.

Противоречия между блоками называть прямо. Расхождение между обещанием роста и юнит-экономикой - это и есть главный вывод, а не шероховатость.
